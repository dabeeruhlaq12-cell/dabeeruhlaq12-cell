## How I work with AI

I bring the problem, domain constraints, and decisions about what the software needs to do. I use AI coding tools to explore designs, draft code and tests, and iterate. I look for evidence a reviewer can check directly, such as a reproducible build, a tested workflow, a source-linked dataset, or the precise statement of a formal theorem.
